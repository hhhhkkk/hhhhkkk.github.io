# 让我们开始

直到现在我也不能完全确定，用 `生活的` 来限定 `质量` 和 `情调`，是否对这次争论来说有以偏概全之嫌。

## 质量

质量问题不得不拆成两个话题来讲了

### 生活的质量

太太总嫌我活的过于粗糙，不精细。可用可不用，不用，可有可没有，没有。例如，短袖领口、袖口都已经磨花了，继续穿, 浴巾都已经快变成搓澡巾了， 继续用，馒头放了几天了，外壳有点硬，没酸继续吃。以上内容在短视频中以扎堆的形式出现时，多数为人妻调侃、吐槽自家男人的，但我实际也真就活成那个样，有就行， 不讲究， 比如我的 i7-4700, gtx970 至今仍在服役。

早在 22 年还是 23 年时，偶然看到了说之后运营商会开通 ESIM 服务，当时还保有些许运动习惯的我， 想买个智能手表来配合使用，当时想的就是，ESIM 联网， 电话、支付宝支付、蓝牙又都支持了， 户外跑跑步啊、篮球啊可以不带手机出门了。一方面减少了装备数量，另一方面还可以监控一下运动时长、心率、热量消耗等，相当于一个多少有点用的玩具了，更何况还有装饰属性，挺好的。

后面我就去店里看了看，但当时市面上适配的就那几款，价格也偏高，就此作罢。

上半年，太太购置了心心念念好久的 LV 和 Iphone 17PM。就在上周， 提到要我给她看看 apple watch. 我问她做什么用， 她说好看。我有些不开心：我早就想买了， 且也不只是为了装饰，由于经济问题我都没买，你这么轻描淡写，张嘴就来。

这是近期关于钱的一件事， 接下来是另外一件事。

上半年前期媳妇经常找我哭穷，当时没查账，再加上一部分确实是她用于家庭开支的，我就补贴了一些，比如买包买手机，还有用于生活的转账。结果某天还找我要钱。我没给且颇有微词， 然后她为了哄我， 告诉我，她偷偷攒了 2 个月工资，一分没动。 我心态崩了， 合计在这里跟我玩家庭版的崩老头呢？ 鉴于其之前就有“藏“私房钱的行为， 我大发雷霆。 

私房钱一说， 是当时我上交工资，每月只给自己留 3000 元用于自己的生活开支， 剩下的转给她，后面发现她有张卡里还有万余元，发现后告诉我这是她辛辛苦苦攒下来的“私房钱“，主要用于我不同意她满足她个人小爱好的开销，比如popmart 等爱好。 由这件事开始，我拒绝上交工资。

由浅入深，我家这本经济账，我也不知道该怎么评价了。

### 太太的质量

这是这篇作文的起因。声明: 我不否认客观存在的一切事实。

太太在产前BMI就已经属于超重，且没有运动基础， 也确实因为生产、哺乳等一系列客观原因， 产后在之前的基础上，仍没有恢复。再加上工作压力， 以及跟我的消费观念不匹配，导致可能没有那么开心，比如看视频会员不是买的是借的，不买超前点播、不让买拉布布 （已有至少 5 个）、我父母来带孩子， 一些生活习惯、做事理念不合等综合原因吧，让她感觉生活也有压力。 那么好， 再加上她是那种高内耗的性格。计算公式就为:

工作压力 => 熬夜、吃点甜的
生活压力 => 吃点好的、买点感兴趣的
容貌、身材焦虑 => 不吃饭

> 再次声明: 以上是我主观判断。

晚上临睡觉，跟我商量想试试替尔泊肽。

我个人极度反感这种“邪修“，就比如 `vibe coding` 提到的口号: 什么技术不重要，什么人人+AI 都等于一个团队， 什么程序员已死，什么3天开发出个网站， 结果一发地址: localhost:3000 。

我提到，首先应调整饮食、作息、找到解压方案、减轻压力， 再加上药物辅助，我认为可行。结果对她来说，我是在阻碍她。

就像是，她一直颈椎不舒服，老是想我给他按按，在前提是多次医院就诊后，医生给到的诊断就是职业病， 要多运动下， 我提出： 我按可以， 你自己先运动运动而不是葛优躺。又吵了一架： 我认为我是你妻子， 应当无条件、无理由帮助我。 我的观点：你应当先自救，让我看到你确实想变好，我可以无条件提供帮扶。 

## 情调

我在考虑， 再找她谈一次， 不要站在一个类似“官方“的角度去与她沟通， 而是平视。 大概分为 3 个方向

1. 每天晚上共同锻炼
2. 购入 2 台智能手表
3. 保持下去，去医院。
